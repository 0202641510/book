# YES24 분야별 베스트셀러 수집기

Streamlit과 BeautifulSoup을 이용해 YES24 분야별 베스트셀러 1페이지(24권) 데이터를 수집하고, 표·차트·CSV 다운로드 기능을 제공하는 웹 앱입니다.

## 주요 기능
- 분야 선택(`selectbox`) 후 버튼 클릭으로 베스트셀러 데이터 수집
- 순위, 제목, 저자, 출판사, 판매가, 판매지수 추출 및 숫자 데이터 정수 변환
- 전체 목록 표(`st.dataframe`) 출력
- 판매지수 상위 10권 가로 막대 차트(`st.bar_chart`) 시각화
- 수집 결과 CSV 파일 다운로드(`st.download_button`, `utf-8-sig` 인코딩)
- 연결 실패, 시간 초과, HTTP 오류, 빈 데이터 예외 처리

## 설치 방법
터미널 또는 명령 프롬프트에서 아래 명령어로 필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

## 실행 방법
`app.py`가 저장된 폴더 위치에서 아래 명령어를 실행합니다.

```bash
streamlit run app.py
```
